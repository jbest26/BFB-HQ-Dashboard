How sync works
Your data is saved to a private GitHub Gist — a secret JSON file only you can access. It syncs automatically 3 seconds after any change. Works on any device where you open this file. localStorage is always kept as a fallback if sync is unavailable.
Step 1 — Create a GitHub token

Go to github.com → Settings → Developer settings → Personal access tokens → Tokens (classic). Generate a new token with only the gist scope. Copy it — you only see it once.
